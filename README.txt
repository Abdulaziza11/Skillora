# Skillora Academy

To'liq responsive frontend demo.

## Fayllar
- index.html — sayt tuzilishi
- styles.css — dizayn va responsive
- script.js — menyu, kurs filteri, modal va forma interaktivligi

## Ishga tushirish
1. Papkani VS Code'da oching.
2. `index.html` ni Live Server bilan ishga tushiring.
3. Yoki `index.html` faylini brauzerda oching.
